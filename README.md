# AdGenius AI

A starter web app that generates advertising copy for Instagram, Google, LinkedIn, and WhatsApp, including A/B variants, language versions, audience copy, copy-review tips, trust checks, budget suggestions, a campaign concept, and an A/B test plan.

## Run locally
1. Install Python 3.10 or newer.
2. Open a terminal in this folder.
3. Run `pip install -r requirements.txt`
4. Run `python app.py`
5. Open `http://127.0.0.1:5000`

This starter uses a simple local template generator and does not need an API key. To use a real AI model, integrate a provider securely on the server. Do not put API keys in browser JavaScript or commit them to GitHub.

The budget and trust outputs are suggestions, not forecasts, legal advice, or compliance guarantees. This app creates copy but does not publish ads directly to advertising platforms.
